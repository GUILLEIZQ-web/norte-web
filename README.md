# Norte Web — sitio listo para GitHub Pages

Versión profesional del portafolio de Norte Web preparada para publicarse en:

`https://guilleizq-web.github.io/norte-web/`

## Cómo subirla

1. Sube **el contenido de esta carpeta** a la raíz del repositorio `norte-web`.
2. Conserva exactamente las carpetas `assets/` y `demos/`.
3. En GitHub abre **Settings → Pages**.
4. Selecciona **Deploy from a branch → main → / (root)**.
5. Espera unos minutos y comprueba la página principal y las demos destacadas.

## Contacto de Norte Web

El WhatsApp principal está centralizado en `assets/site-config.js`.

- Formato: código de país y número, solo dígitos.
- Número configurado: `50663838303`.
- La URL pública oficial también está guardada en ese archivo.

## Dato pendiente de Puppy Fashion

La clienta indicó que su WhatsApp Business es diferente del número personal anterior. Para evitar dirigir consultas al número equivocado:

- El número anterior fue eliminado de la demo.
- Mientras no se confirme el nuevo número, los botones abren Instagram.
- Cuando se confirme, edita únicamente `demos/puppy-fashion/assets/site-config.js` y completa `whatsappBusiness` con el formato `506XXXXXXXX`.

## Transparencia de las demos

- Las propuestas para negocios reales usan `noindex,nofollow` y muestran un aviso de información por confirmar.
- Las marcas ficticias están identificadas como demos de portafolio.
- No deben atribuirse ventas, resultados o relación comercial a un negocio que todavía no haya contratado el servicio.
- `noindex` evita que una propuesta se posicione en buscadores, pero no la vuelve privada.
