# Norte Web — portafolio inicial

Portafolio estático pensado para publicarse gratis en GitHub Pages.

## Antes de publicar

1. Edita `assets/site-config.js` con tu nombre, número de WhatsApp (solo dígitos con código de país) y correo.
2. Abre `index.html` en el navegador para revisarlo.
3. Sube esta carpeta a un repositorio público de GitHub y activa **Settings → Pages → Deploy from a branch → main / root**.

Los tres proyectos dentro de `demos/` son demostraciones de marcas ficticias. No los presentes como trabajos pagados.
